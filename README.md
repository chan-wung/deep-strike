# Deep Strike (딥 스트라이크)

노란 잠수함으로 바다 생물 편대를 어뢰로 물리치는 갤러그형 슈팅 게임입니다. 순수 JavaScript와 `<canvas>`로 만들었고 게임 엔진은 쓰지 않았습니다.
캐릭터·그래픽은 모두 직접 그렸습니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # dist/ 에 배포용 빌드
npm test         # 게임 규칙 테스트
```

Node.js 20.19 이상(또는 22.12 이상)이 필요합니다. 휴대폰에서는 같은 와이파이로 개발 서버 주소에 접속하면 됩니다.

## 조작

| 환경 | 방법 |
|---|---|
| 키보드 | 방향키 ← → 또는 A D 로 이동, Space · Z · ↑ 로 발사 (누르고 있으면 연사) |
| 터치 | 화면을 누르고 있으면 자동으로 발사, 누른 채 좌우로 끌면 잠수함이 따라옵니다 |
| 일시정지 | P · Esc 키, 또는 왼쪽 위 ⏸ 버튼. 멈춘 화면에서 다시 누르거나 화면을 터치하면 계속합니다. 다른 탭으로 가면 자동으로 멈춥니다 |
| 시작·다시 하기 | 시작 화면과 게임 오버 화면에서 아무 키나 누르거나 화면을 터치 |

터치 조작은 터치 기기에서 자동으로 켜지고, 주소 끝에 `?touch=1`을 붙이면 PC에서도 켤 수 있습니다. 오른쪽 위 버튼으로 한국어와 영어를 바꿀 수 있습니다.

## 규칙

- 적은 5번에 나누어 경로를 따라 들어와 40칸 대열을 채웁니다. 다 모이면 대열이 벌어졌다 오므라들고, 그 사이 한두 마리씩 급강하해 탄을 쏘며 덤빕니다. 급강하 중에 잡으면 점수가 두 배입니다.
- 어뢰는 화면에 두 발까지(쌍둥이면 네 발) 있을 수 있습니다. 적의 탄이나 몸에 닿으면 잠수함을 잃습니다. 잠수함은 3대로 시작하고 20000점, 70000점, 이후 70000점마다 하나 더 받습니다.
- 모든 적을 잡으면 다음 스테이지로 넘어가고, 스테이지가 오를수록 더 자주·더 빠르게·더 많이 덤빕니다.

| 적 | 대열 / 급강하 점수 | 특징 |
|---|---|---|
| 해파리 | 50 / 100 | |
| 복어 | 80 / 160 | |
| 문어 | 150 / 400 | 두 발을 맞혀야 잡히고, 한 발 맞으면 색이 변합니다. 복어 둘을 데리고 급강하할 때 잡으면 800 · 1600점 |

### 문어의 소용돌이와 쌍둥이 잠수함

- 문어가 잠수함 위에 멈춰 소용돌이를 펼치고, 그 안에 들어가면 잠수함이 빨려 올라가 납치됩니다. 예비 잠수함이 없거나(마지막 한 대), 이미 쌍둥이이거나, 이미 납치된 잠수함이 있으면 소용돌이를 펼치지 않습니다.
- 납치한 문어는 잠수함을 머리에 이고 대열로 돌아갑니다. 이 문어가 **급강하할 때 잡으면** 잠수함이 풀려나 옆에 붙어 **쌍둥이 잠수함**이 됩니다. 어뢰가 두 줄로 나가지만 맞는 폭도 넓어지고, 한 대를 잃어도 나머지로 계속합니다.
- 대열에 있을 때 잡으면 구하지 못하고, 납치된 잠수함이 붉은 적 잠수함이 되어 덤벼듭니다.

### 보너스 스테이지

3 · 7 · 11 … 스테이지는 물고기 떼 40마리가 헤엄쳐 지나갑니다. 공격하지 않으며 한 마리에 100점이고, 모두 맞히면 퍼펙트 10000점입니다. 게임 오버 화면에서는 발사 수·명중 수·명중률을 보여 줍니다. 최고 점수는 브라우저에 저장됩니다.

## 구조

```
src/
  game/    규칙 (화면·키보드를 모르므로 node 에서 바로 테스트)
    paths.js      입장·급강하·보너스·소용돌이 경로 (베지어)
    formation.js  40칸 대열: 흔들기와 벌어졌다 오므라들기
    enemy.js      적 한 마리의 상태 (입장 → 대열 → 급강하 → 재입장, 문어의 소용돌이)
    player.js     잠수함·어뢰·쌍둥이
    stage.js      스테이지별 적 구성, 보너스 스테이지 판정
    game.js       점수·목숨·충돌·납치와 구출·단계 진행
  render/  canvas 그리기
  ui/      터치 조작
  app/     i18n (ko/en)
tests/     paths · formation · player · enemy · game · i18n
```

화면 크기는 224×288 논리 좌표이고 canvas 에는 2배로 그립니다. 속도·간격 같은 조정값은 `game.js`(`diveSpeed`, `maxDivers`, `diveInterval`)와 `enemy.js`(`SPD`, `BEAM_*`)에 모여 있습니다.
