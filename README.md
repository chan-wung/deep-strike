# Deep Strike (딥 스트라이크)

노란 잠수함으로 바다 생물 편대를 어뢰로 물리치는 갤러그형 슈팅 게임입니다. 순수 JavaScript와 `<canvas>`로 만들었고 게임 엔진은 쓰지 않았습니다.
캐릭터·그래픽·효과음은 모두 직접 그리고 합성했습니다(이미지·음원 파일 없음).

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # dist/ 에 배포용 빌드
npm test         # 게임 규칙 테스트
```

Node.js 20.19 이상(또는 22.12 이상)이 필요합니다. 휴대폰에서는 같은 와이파이로 개발 서버 주소에 접속하면 됩니다.

## 조작

| 환경 | 방법 |
|---|---|
| 키보드 | 방향키 ← → 또는 A D 로 이동, Space · Z · ↑ 로 발사 (누르고 있으면 연사), X · B · Shift 로 필살기(해일) |
| 터치 | 화면을 누르고 있으면 자동으로 발사, 누른 채 좌우로 끌면 잠수함이 따라옵니다. 오른쪽 아래 🌊 버튼이 필살기 |
| 일시정지 | P · Esc 키, 또는 왼쪽 위 ⏸ 버튼. 멈춘 화면에서 다시 누르거나 화면을 터치하면 계속합니다. 다른 탭으로 가면 자동으로 멈춥니다 |
| 소리 | M 키 또는 왼쪽 위 🔊 버튼으로 켜고 끕니다 (설정은 저장됩니다) |
| 난이도 | 시작·게임 오버 화면에서 ← → 키 또는 왼쪽 아래 버튼. 쉬움·보통·어려움을 모두 깨면 **무한**이 목록에 나타납니다 |
| 이름 입력 | 점수판(상위 10위)에 오르면 게임 오버·엔딩 결과 화면에서 이름 입력 칸이 뜹니다. 최대 8글자(한글 가능), Enter 또는 확인으로 올리고, Esc 는 지난번 이름으로 올립니다 |
| 시작·다시 하기 | 시작 화면과 게임 오버 화면에서 아무 키나 누르거나 화면을 터치 |

터치 조작은 터치 기기에서 자동으로 켜지고, 주소 끝에 `?touch=1`을 붙이면 PC에서도 켤 수 있습니다. 오른쪽 위 버튼으로 한국어와 영어를 바꿀 수 있습니다.

## 규칙

- 적은 5번에 나누어 경로를 따라 들어와 40칸 대열을 채웁니다. 다 모이면 대열이 벌어졌다 오므라들고, 그 사이 한두 마리씩 급강하해 탄을 쏘며 덤빕니다. 급강하 중에 잡으면 점수가 두 배입니다. 4 스테이지부터는 곡선 없이 빠르게 내리꽂히는 **돌진**도 나옵니다.
- 어뢰는 화면에 두 발까지(쌍둥이면 네 발) 있을 수 있습니다. 적의 탄이나 몸에 닿으면 잠수함을 잃습니다. 잠수함은 3대로 시작하고 20000점, 70000점, 이후 70000점마다 하나 더 받습니다.
- 모든 적을 잡으면 다음 스테이지로 넘어가고, 스테이지가 오를수록 더 자주·더 빠르게·더 많이 덤빕니다. 바다도 스테이지가 오를수록 깊고 어두워집니다.
- **엔딩**: 쉬움·보통·어려움은 15 스테이지의 거대 가오리를 쓰러뜨리면 끝납니다. 남은 잠수함 한 대마다 10000점 보너스를 받고 엔딩 이야기가 나온 뒤 결과 화면으로 넘어갑니다. 엔딩을 본 난이도에는 ★ 가 붙습니다(이 기기의 브라우저에 저장).
- **무한 모드**: 쉬움·보통·어려움을 **모두** 엔딩까지 깨야 열립니다. 어려움과 같은 설정으로 시작하고, 15 스테이지에서 끝나지 않고 지금까지처럼 보스가 번호에 따라 강해지며 끝없이 이어집니다(엔딩 없음).

| 적 | 대열 / 급강하 점수 | 특징 |
|---|---|---|
| 해파리 | 50 / 100 | |
| 복어 | 80 / 160 | |
| 문어 | 150 / 400 | 두 발을 맞혀야 잡히고, 한 발 맞으면 색이 변합니다. 복어 둘을 데리고 급강하할 때 잡으면 800 · 1600점 |
| 전기뱀장어 | 100 / 200 | 2 스테이지부터. 탄 없이 화면을 가로로 길게 가로지릅니다 |
| 가오리 | 120 / 240 | 4 스테이지부터. 지그재그로 내려오며 3갈래로 쏩니다 |
| 거북 | 200 / 400 | 6 스테이지부터. 체력 3(맞을수록 껍질 색이 변함), 느리지만 단단합니다 |
| 폭탄 복어 | 100 / 200 | 8 스테이지부터. 잡으면 사방 8방향으로 탄이 터집니다 (잡을 때 거리를 두세요) |

### 스테이지가 오를수록

- **대열 모양**이 바뀝니다. 직사각형 → 피라미드 → 역삼각형 → 다이아몬드 → 가운데가 빈 양 날개 순서로 돌아가며, 어느 모양이든 40칸입니다.
- **새 적**이 해파리·복어 자리를 차지하고, 스테이지가 오를수록 수가 늘어납니다. 어떤 자리가 바뀔지는 정해져 있어서 난수에 좌우되지 않습니다.
- **입장 방식**이 바뀝니다. 입장 경로 조합과 들어오는 간격이 달라지고, 한 웨이브가 양쪽에서 동시에 들어오는 스테이지도 있습니다.
- **공격 방식**이 늘어납니다. 4 스테이지부터 곡선 없이 빠르게 내리꽂히는 **돌진**, 6 스테이지부터 같은 종류 두세 마리가 함께 내려오는 **편대 급강하**(10 스테이지부터는 다섯 마리까지), 폭탄 복어의 폭발이 더해집니다.
- 바다도 점점 깊고 어두워지고, 5 스테이지마다 **보스**가 나옵니다.

3 · 7 · 11 … 은 보너스 스테이지, 5 · 10 · 15 … 는 보스 스테이지입니다(번호가 겹치면 보스가 먼저). 두 종류는 모양·새 적 순번을 세지 않습니다.

### 필살기: 해일

적을 잡으면 아래 가운데의 게이지가 차고(해파리 +3 · 복어 +4 · 문어 +8, 급강하 중이면 두 배), 가득 차면 `X`로 해일을 일으킵니다.
쓴 순간 잠수함 위치를 중심으로 폭 약 70px(화면의 3분의 1) **기둥**이 바닥에서 위로 쓸어 올라가며, 그 안의 적 탄을 지우고 적에게 피해 1을 줍니다(크라켄에게는 10).
해파리·복어는 한 번에 잡히지만 문어(체력 2)는 버텨 냅니다. 기둥 바깥의 적과 탄은 그대로이니 적이 모인 곳을 보고 조준해서 쓰세요. 해일이 지나는 동안은 맞지 않습니다.
보너스 스테이지에서는 쓸 수 없고, 잠수함을 잃으면 게이지도 사라집니다. 크라켄을 쓰러뜨리면 게이지가 가득 찹니다.

### 아이템

일부 적은 아이템을 품고 나오는데, 그런 적은 **아이템 색으로 반짝입니다**(노랑 R · 하늘색 S · 파랑 W). 반짝이는 적을 잡으면 반드시 떨어뜨리고(해일로 잡아도 마찬가지), 잠수함에 닿으면 먹습니다. 어떤 적이 품을지는 스테이지가 시작될 때 정해지고, 난이도에 따라 품은 적의 비율이 다릅니다.

| 아이템 | 효과 |
|---|---|
| R 연사 강화 | 10초 동안 더 빨리, 화면에 세 발까지 |
| S 방어막 | 한 번 맞는 것을 막습니다 (쌍둥이도 지켜 줍니다) |
| W 해일 충전 | 필살기 게이지 +40 |
| V 확산탄 | 어뢰 대신 세 갈래 부채꼴로 쏩니다 (넓게 덮지만 한 줄당 힘은 그대로) |
| L 레이저 | 빠른 광선이 일렬로 선 적을 **꿰뚫습니다**. 한 발이 같은 적은 한 번만 맞히고, 보스에게는 발당 1 |
| H 유도탄 | 가까운 적(보스)을 향해 천천히 휘어 갑니다 |

새 무기(V·L·H)는 **15초** 동안 기본 어뢰 대신 쓰입니다. 다른 무기를 먹으면 바뀌고 시간이 새로 차며, 다음 스테이지로 넘어가도 남은 시간은 이어지지만 **잠수함을 잃으면 사라집니다**. 연사 강화와 쌍둥이 잠수함에도 그대로 적용됩니다(레이저·유도탄은 연사 강화 효과가 조금 작습니다). 보스는 사나워질 때마다(2·3단계) 그 스테이지에서 나올 수 있는 무기 하나를 떨어뜨립니다.

어떤 아이템이 나오는지는 스테이지와 난이도에 따라 다릅니다. 무기는 처음부터 나오지 않고 스테이지가 올라야 열립니다.

| 무기가 처음 나오는 스테이지 | 쉬움 | 보통 | 어려움 · 무한 |
|---|---|---|---|
| 확산탄 | 1 | 2 | 3 |
| 레이저 | 3 | 4 | 5 |
| 유도탄 | 6 | 7 | 8 |

아이템 종류의 비중(가중치)도 난이도마다 달라서, 쉬움은 방어막·유도탄이 후하고 어려움·무한은 방어막이 짜고 레이저·해일 충전이 많습니다.

| 가중치 | R | S | W | V | L | H |
|---|---|---|---|---|---|---|
| 쉬움 | 3 | 4 | 2 | 3 | 2 | 3 |
| 보통 | 3 | 3 | 2 | 3 | 2 | 2 |
| 어려움 · 무한 | 3 | 2 | 3 | 2 | 3 | 1 |

### 보스 스테이지

5 · 10 · 15 … 스테이지에는 대열 대신 보스가 나옵니다. 보스는 **크라켄 → 심해 아귀 → 거대 가오리** 순서이고, 거대 가오리(15)가 마지막 보스입니다(엔딩). 무한 모드에서만 20 스테이지부터 다시 크라켄으로 돌아가며 이어집니다. 체력이 줄면 세 번 사나워집니다.
쓰러뜨리면 5000점 × 보스 번호(5스테이지 5000점, 10스테이지 10000점…)와 해일 게이지 가득이고, 체력은 보스 번호가 오를수록 커집니다(60 · 90 · 120 …).

| 보스 | 싸우는 방식 |
|---|---|
| 크라켄 (5) | 1단계 플레이어를 겨눈 3갈래 먹물 → 2단계 5갈래 부채꼴과 조준탄, 해파리 소환 → 3단계 빙글 도는 먹물 고리, 해파리를 더 자주 소환 |
| 심해 아귀 (10) | 머리의 빛 미끼에서 먹물을 쏘고, 주기적으로 입을 벌리고 **아래로 돌진**합니다(이때 몸에 닿으면 죽습니다). 2단계부터는 가끔 **화면이 어두워져** 미끼 주변만 보이고(탄은 계속 보입니다), 3단계에서는 먹물 고리와 더 잦은 돌진 |
| 거대 가오리 (15) | 가로 9칸에 두 칸만 비어 있는 **먹물 장막**이 내려오고 빈틈으로 빠져나가야 합니다. 2단계에서 조준 3갈래가 더해지고, 3단계에서 폭탄 복어를 떨어뜨립니다 |

### 문어의 소용돌이와 쌍둥이 잠수함

- 문어가 잠수함 위에 멈춰 소용돌이를 펼치고, 그 안에 들어가면 잠수함이 빨려 올라가 납치됩니다. 예비 잠수함이 없거나(마지막 한 대), 이미 쌍둥이이거나, 이미 납치된 잠수함이 있으면 소용돌이를 펼치지 않습니다.
- 납치한 문어는 잠수함을 머리에 이고 대열로 돌아갑니다. 이 문어가 **급강하할 때 잡으면** 잠수함이 풀려나 옆에 붙어 **쌍둥이 잠수함**이 됩니다. 어뢰가 두 줄로 나가지만 맞는 폭도 넓어지고, 한 대를 잃어도 나머지로 계속합니다.
- 대열에 있을 때 잡으면 구하지 못하고, 납치된 잠수함이 붉은 적 잠수함이 되어 덤벼듭니다.

### 보너스 스테이지

3 · 7 · 11 … 스테이지는 물고기 떼 40마리가 헤엄쳐 지나갑니다. 공격하지 않으며 한 마리에 100점이고, 모두 맞히면 퍼펙트 10000점입니다.

### 기록과 공유

게임 오버나 엔딩이 되면 결과 화면으로 넘어갑니다. 점수판은 **모드(쉬움·보통·어려움·무한)마다 따로** 있고, 각각 이 기기의 브라우저에 **상위 10개**까지 저장됩니다(서버로 보내지 않습니다). 이번 점수가 그 모드 10위 안에 들면(10위와 같은 점수는 제외) **이름을 입력**하고, 순위 · 이름 · 점수 · 스테이지 · 클리어 ★ 를 보여 줍니다. 이번 판 순위는 강조되고, 결과 화면에서 ← → 로 다른 모드의 점수판도 볼 수 있습니다. 시작 화면에는 지금 모드의 최고 점수가 나옵니다.
예전 버전의 기록(모드 구분 없이 한 목록)은 처음 열 때 기록에 적힌 난이도대로 각 점수판에 옮겨지고, 이름은 `---`로 표시됩니다.
**공유** 버튼은 이름이 들어간 점수 카드 이미지를 만들어 공유 창을 띄웁니다(휴대폰). 공유를 지원하지 않는 브라우저에서는 문구를 클립보드에 복사합니다. **이미지 저장** 버튼은 카드를 PNG 로 내려받습니다.

```
    stage.js      스테이지별 대열 모양·새 적 섞기·입장 패턴, 보너스·보스 스테이지 판정
    game.js       점수·목숨·충돌·납치와 구출·필살기·아이템·난이도·단계 진행·엔딩·무한 모드 해금·이름 받기
  render/  canvas 그리기 (render.js), 공유 카드 이미지 (card.js)
  ui/      터치 조작
  app/     i18n (ko/en), 모드별 내 기록·이름 (records.js), 효과음 합성 (sound.js)
tests/     paths · formation · player · enemy · stages · kraken · extras · weapons · ending · game · records · i18n
```

화면 크기는 224×288 논리 좌표이고 canvas 에는 2배로 그립니다. 게임 규칙은 효과음이 필요한 순간에 이벤트 이름(`game.events`)만 남기고, `main.js`가 그것을 `sound.js`로 넘깁니다.
속도·간격 같은 조정값은 `game.js`(`DIFFICULTIES`, `FINAL_STAGE`, `diveSpeed`, `maxDivers`, `diveInterval`, 해일 상수)와 `enemy.js`(`SPD`, `BEAM_*`), 스테이지 구성은 `stage.js`(`MIX`, `ENTRY_PATTERNS`)에, 보스 패턴은 각 보스 파일에, 무기와 아이템 분배는 `weapons.js`(`WEAPON_DEF`, `WEAPON_FROM`, `ITEM_WEIGHTS`)에 모여 있습니다.
브라우저 저장소 키는 `deepstrike.records`(모드별 점수판), `deepstrike.clears`(엔딩을 본 난이도), `deepstrike.name`(마지막 이름), `deepstrike.diff`, `deepstrike.lang`, `deepstrike.mute` 입니다.
