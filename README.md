# Deep Strike (딥 스트라이크)

노란 잠수함으로 바다 생물 편대를 어뢰로 물리치는 갤러그형 슈팅 게임입니다. 순수 JavaScript와 `<canvas>`로 만들었고 게임 엔진은 쓰지 않았습니다.
캐릭터·그래픽·효과음·배경 음악은 모두 직접 그리고 합성했습니다(이미지·음원 파일 없음).

## 실행

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # dist/ 에 배포용 빌드
npm test         # 게임 규칙 테스트
```

Node.js 20.19 이상(또는 22.12 이상)이 필요합니다. 휴대폰에서는 같은 와이파이로 개발 서버 주소에 접속하면 됩니다.

## 조작

| 환경 | 방법 |
|---|---|
| 키보드 | 방향키 ← → 또는 A D 로 이동, Space · Z · ↑ 로 발사 (누르고 있으면 연사), X · B · Shift 로 필살기. 기체 고르기·결과 화면에서는 ← → 로 잠수함을 고릅니다 |
| 터치 | 화면을 누르고 있으면 자동으로 발사, 누른 채 좌우로 끌면 잠수함이 따라옵니다. 오른쪽 아래 버튼(🌊·📡·💥, 기체마다 다름)이 필살기. 기체 고르기 화면에서는 카드를 눌러 고른 뒤 출발 버튼, 결과 화면에서는 ◀ ▶ 로 잠수함을 고릅니다 |
| 일시정지 | P · Esc 키, 또는 왼쪽 위 ⏸ 버튼. 멈춘 화면에서 다시 누르거나 화면을 터치하면 계속합니다. 다른 탭으로 가면 자동으로 멈춥니다 |
| 소리 | 효과음은 M 키 또는 왼쪽 위 🔊 버튼, 배경 음악은 N 키 또는 🎵 버튼으로 따로 켜고 끕니다 (설정은 저장됩니다) |
| 이름 입력 | 점수판(상위 10위)에 오르면 게임 오버·엔딩 결과 화면에서 이름 입력 칸이 뜹니다. 최대 8글자(한글 가능), Enter 또는 확인으로 올리고, Esc 는 지난번 이름으로 올립니다 |
| 시작·다시 하기 | 시작 화면(게임 이름과 설명)에서 아무 키나 누르거나 터치하면 **잠수함 고르기** 화면이 열리고, 거기서 ← → 로 고르고 아무 키나 누르면 출발합니다. 게임 오버 화면에서는 아무 키나 누르거나 터치하면 바로 다시 시작합니다 (결과 화면이 나오고 1초 뒤부터) |

터치 조작은 터치 기기에서 자동으로 켜지고, 주소 끝에 `?touch=1`을 붙이면 PC에서도 켤 수 있습니다. 오른쪽 위 버튼으로 한국어와 영어를 바꿀 수 있습니다.

## 잠수함 고르기

시작 화면 다음의 **잠수함 고르기 화면**에서 세 기체를 카드로 나란히 보고(공격·속도·시작 폭탄·필살기) 하나를 고릅니다. 게임 오버·엔딩 결과 화면 아래쪽의 ◀ ▶ 로도 다시 고를 수 있습니다. 마지막에 고른 기체는 기억합니다. 기체마다 **기본 공격 · 이동 속도 · 시작 폭탄 · 필살기**가 다르고, 아이템 무기(15초)가 끝나거나 잠수함을 잃으면 자기 기본 공격으로 돌아옵니다.

| 기체 | 기본 공격 | 이동 | 폭탄 | 필살기 |
|---|---|---|---|---|
| 노랑 잠수함 | 어뢰 한 줄 | 보통 | 3 | **대해일** |
| 청록 다트 | 가는 바늘 두 줄 (어뢰보다 약간 느리다) | 빠름 | 2 | **어뢰 폭풍** |
| 주황 해머 | 적 둘을 꿰뚫는 굵은 어뢰 (발사 간격이 길다) | 느림 | 4 | **심해 폭격** |

기록(점수판)과 공유 카드에도 기체가 표시됩니다. 기체 정보가 없던 예전 기록은 노랑 잠수함으로 읽습니다.

## 규칙

- 적은 5번에 나누어 경로를 따라 들어와 40칸 대열을 채웁니다. 다 모이면 대열이 벌어졌다 오므라들고, 그 사이 한두 마리씩 급강하해 탄을 쏘며 덤빕니다. 급강하 중에 잡으면 점수가 두 배입니다. 4 스테이지부터는 곡선 없이 빠르게 내리꽂히는 **돌진**도 나옵니다.
- 어뢰는 화면에 두 발까지(쌍둥이면 네 발) 있을 수 있습니다. 적의 탄이나 몸에 닿으면 잠수함을 잃습니다. 잠수함은 3대로 시작하고 20000점, 70000점, 이후 70000점마다 하나 더 받습니다.
- 모든 적을 잡으면 다음 스테이지로 넘어가고, 스테이지가 오를수록 더 자주·더 빠르게·더 많이 덤빕니다. 바다도 스테이지가 오를수록 깊고 어두워집니다.
- **엔딩**: 20 스테이지 **LAST STAGE**의 심해의 왕 리바이어던을 쓰러뜨리면 끝납니다. 남은 잠수함 한 대마다 10000점 보너스를 받고 엔딩 이야기가 나온 뒤 결과 화면으로 넘어갑니다. 엔딩을 본 기록에는 ★ 가 붙습니다.
- **콤보**: 1.5초 안에 또 잡으면 이어지는 콤보로 점수에 배율이 붙습니다. 10마리마다 ×0.5씩 올라 최대 ×3이고, 1.5초 동안 못 잡거나 잠수함을 잃거나 스테이지가 바뀌면 끊깁니다. 보스 격파 점수와 보너스 스테이지에는 붙지 않습니다.
- **난이도는 하나**입니다. 11 스테이지부터는 적 탄이 1.1배 빨라지고 동시에 급강하하는 적이 하나 더 늘어납니다.

| 적 | 대열 / 급강하 점수 | 특징 |
|---|---|---|
| 해파리 | 50 / 100 | |
| 복어 | 80 / 160 | |
| 문어 | 150 / 400 | 두 발을 맞혀야 잡히고, 한 발 맞으면 색이 변합니다. 복어 둘을 데리고 급강하할 때 잡으면 800 · 1600점 |
| 전기뱀장어 | 100 / 200 | 2 스테이지부터. 탄 없이 화면을 가로로 길게 가로지릅니다 |
| 가오리 | 120 / 240 | 4 스테이지부터. 지그재그로 내려오며 3갈래로 쏩니다 |
| 거북 | 200 / 400 | 6 스테이지부터. 체력 3(맞을수록 껍질 색이 변함), 느리지만 단단합니다 |
| 폭탄 복어 | 100 / 200 | 8 스테이지부터. 잡으면 사방 8방향으로 탄이 터집니다 (잡을 때 거리를 두세요) |

### 스테이지가 오를수록

- **대열 모양**이 바뀝니다. 직사각형 → 피라미드 → 역삼각형 → 다이아몬드 → 가운데가 빈 양 날개 순서로 돌아가며, 어느 모양이든 40칸입니다.
- **새 적**이 해파리·복어 자리를 차지하고, 스테이지가 오를수록 수가 늘어납니다. 어떤 자리가 바뀔지는 정해져 있어서 난수에 좌우되지 않습니다.
- **입장 방식**이 바뀝니다. 입장 경로 조합과 들어오는 간격이 달라지고, 한 웨이브가 양쪽에서 동시에 들어오는 스테이지도 있습니다.
- **공격 방식**이 늘어납니다. 4 스테이지부터 곡선 없이 빠르게 내리꽂히는 **돌진**, 6 스테이지부터 같은 종류 두세 마리가 함께 내려오는 **편대 급강하**(10 스테이지부터는 다섯 마리까지), 폭탄 복어의 폭발이 더해집니다.
- 바다도 점점 깊고 어두워지고, 5 스테이지마다 **보스**가 나옵니다 (5 · 10 · 15 · 20).

보너스 스테이지는 판마다 **1~9 구간에 한 번, 11~19 구간에 한 번** 랜덤한 자리에 들어갑니다(보스 스테이지와 겹치지 않습니다). 5 · 10 · 15 · 20 은 보스 스테이지입니다. 두 종류는 모양·새 적 순번을 세지 않습니다. 대열의 입장 경로 순서와 먼저 들어오는 적도 스테이지가 시작될 때마다 섞입니다.

### 필살기

폭탄(아래 가운데의 방울)이 기체마다 정해진 개수로 시작하고(잠수함을 잃은 뒤에도 그 개수로 돌아갑니다, 최대 6개), `X`로 하나씩 씁니다. 보스를 쓰러뜨리거나 W 아이템을 먹으면 하나 늘어납니다. 세 필살기 모두 **화면 전체**를 노리는 큰 기술이고, 쓴 순간 화면이 번쩍이며, 진행되는 동안 잠수함은 맞지 않습니다. 필살기로 잡은 적도 평소처럼 점수와 콤보가 들어옵니다. 보너스 스테이지에서는 쓸 수 없고, 한 번에 하나만 일으킬 수 있습니다.

> 필살기가 너무 강한지(스테이지를 건너뛰는 느낌)는 아직 검토 중입니다. 고려 중인 조정안은 [IDEAS.md](IDEAS.md) 에 있습니다.

| 필살기 | 하는 일 |
|---|---|
| **대해일** (노랑) | 화면 폭 전체의 물결이 바닥에서 위로 쓸어 올라가며 **지나간 자리의 적 탄을 모두 지우고 모든 적에게 피해 2**를 줍니다(해파리·복어·문어는 한 번에 잡히고 거북은 한 칸 남습니다). 보스에게는 20 |
| **어뢰 폭풍** (다트) | 유도 어뢰 **24발**이 부채꼴로 퍼졌다가 **적을 한 마리씩 골라 추적**해 피해 2를 줍니다(목표가 사라지면 가까운 적으로 갈아탑니다). 보스가 있으면 4발에 한 발이 보스로 가고(발당 2), 보스에게 가는 어뢰는 최대 12발입니다. 쏘는 순간 잠수함 주변의 탄이 사라지고 2초 동안 맞지 않습니다 |
| **심해 폭격** (해머) | 화면을 5열 × 3줄로 나눠 **15번의 폭발이 왼쪽에서 오른쪽으로 연쇄**합니다. 폭발마다 반경 46 안의 탄을 지우고 적에게 피해 3(거북도 한 번에), 보스에게 7을 주며, 마지막 폭발에서 화면의 남은 탄이 모두 사라집니다. 보스는 여러 폭발에 겹쳐 맞아 큰 피해를 입습니다 |

### 아이템

일부 적은 아이템을 품고 나오는데, 그런 적은 **아이템 색으로 반짝입니다**(R·S·W·V·L·H·B·N·P·T·F 마다 색이 다릅니다). 반짝이는 적을 잡으면 반드시 떨어뜨리고(필살기로 잡아도 마찬가지), 잠수함에 닿으면 먹습니다. 떨어진 아이템은 화면 안을 벽에 튕기며 돌아다니다가 10초 뒤(마지막 2초는 깜빡)에 사라집니다. 어떤 적이 품을지는 스테이지가 시작될 때 정해지고, 품은 적은 약 12% 입니다.

| 아이템 | 효과 |
|---|---|
| R 연사 강화 | 10초 동안 더 빨리, 화면에 세 발까지 |
| S 방어막 | 한 번 맞는 것을 막습니다 (쌍둥이도 지켜 줍니다) |
| W 필살기 충전 | 폭탄 +1 |
| V 확산탄 | 어뢰 대신 세 갈래 부채꼴로 쏩니다 (넓게 덮지만 한 줄당 힘은 그대로) |
| L 레이저 | 빠른 광선이 일렬로 선 적을 **꿰뚫습니다**. 한 발이 같은 적은 한 번만 맞히고, 보스에게는 발당 1 |
| H 유도탄 | 가까운 적(보스)을 향해 천천히 휘어 갑니다 |
| B 폭발 어뢰 | 맞은 자리에서 터져 주변 적도 함께 맞힙니다 |
| N 음파 링 | 날아가며 넓어지는 링이 적을 꿰뚫습니다 |
| P 추진기 | **영구 강화**: 이동 속도 +1단계 |
| T 어뢰 가속 | **영구 강화**: 어뢰 속도 +1단계 |
| F 장전기 | **영구 강화**: 발사 간격 단축·동시에 날릴 수 있는 어뢰 +1단계 |

새 무기(V·L·H·B·N)는 **15초** 동안 기본 어뢰 대신 쓰입니다. 다른 무기를 먹으면 바뀌고 시간이 새로 차며, 다음 스테이지로 넘어가도 남은 시간은 이어지지만 **잠수함을 잃으면 사라집니다**. 연사 강화와 쌍둥이 잠수함에도 그대로 적용됩니다(레이저·유도탄은 연사 강화 효과가 조금 작습니다). 영구 강화(P·T·F)는 각각 최대 3단계까지 쌓이고(다 쌓은 뒤에 먹으면 1000점), 무기와 달리 시간 제한은 없지만 **잠수함을 잃으면 사라집니다**. 보스는 사나워질 때마다(2·3단계) 그 스테이지에서 나올 수 있는 무기 하나를 떨어뜨립니다.

어떤 아이템이 나오는지는 스테이지에 따라 다릅니다. 무기는 처음부터 나오지 않고 스테이지가 올라야 열립니다.

| 무기 | 처음 나오는 스테이지 |
|---|---|
| 확산탄 | 2 |
| 레이저 | 4 |
| 폭발 어뢰 | 5 |
| 유도탄 | 7 |
| 음파 링 | 9 |

아이템 종류의 비중(가중치)은 R 3 · S 3 · W 2 · V 3 · L 2 · H 2 · B 2 · N 2 · P 1 · T 1 · F 1 입니다 (아직 열리지 않은 무기는 빠집니다).

### 보스 스테이지

5 · 10 · 15 · 20 스테이지에는 대열 대신 보스가 나옵니다. 보스는 **크라켄 → 심해 아귀 → 거대 가오리 → 심해의 왕 리바이어던** 순서이고, 20 스테이지(**LAST STAGE**)의 리바이어던이 마지막 보스입니다(엔딩). 체력이 줄면 세 번 사나워집니다.
쓰러뜨리면 5000점 × 보스 번호(5스테이지 5000점, 10스테이지 10000점…)과 폭탄 +1이고, 체력은 보스 번호가 오를수록 커집니다(60 · 90 · 120 · 150).

| 보스 | 싸우는 방식 |
|---|---|
| 크라켄 (5) | 1단계 플레이어를 겨눈 3갈래 먹물 → 2단계 5갈래 부채꼴과 조준탄, 해파리 소환 → 3단계 빙글 도는 먹물 고리, 해파리를 더 자주 소환 |
| 심해 아귀 (10) | 머리의 빛 미끼에서 먹물을 쏘고, 주기적으로 입을 벌리고 **아래로 돌진**합니다(이때 몸에 닿으면 죽습니다). 2단계부터는 가끔 **화면이 어두워져** 미끼 주변만 보이고(탄은 계속 보입니다), 3단계에서는 먹물 고리와 더 잦은 돌진 |
| 거대 가오리 (15) | 가로 9칸에 두 칸만 비어 있는 **먹물 장막**이 내려오고 빈틈으로 빠져나가야 합니다. 2단계에서 조준 3갈래가 더해지고, 3단계에서 폭탄 복어를 떨어뜨립니다 |
| 심해의 왕 리바이어던 (20) | **LAST STAGE**. 앞 세 보스의 공격을 단계마다 섞어 씁니다. 1단계 조준 3갈래와 느린 먹물 장막 → 2단계 5갈래 조준, 빙글 도는 먹물 고리, 해파리 소환 → 3단계 입을 벌린 **돌진**(몸에 닿으면 죽습니다), 촘촘한 고리, 폭탄 복어 |

### 문어의 소용돌이와 쌍둥이 잠수함

- 문어가 잠수함 위에 멈춰 소용돌이를 펼치고, 그 안에 들어가면 잠수함이 빨려 올라가 납치됩니다. 예비 잠수함이 없거나(마지막 한 대), 이미 쌍둥이이거나, 이미 납치된 잠수함이 있으면 소용돌이를 펼치지 않습니다.
- 납치한 문어는 잠수함을 머리에 이고 대열로 돌아갑니다. 이 문어를 급강하할 때 잡으면 잠수함이 풀려나 옆에 붙어 **쌍둥이 잠수함**이 됩니다. 어뢰가 두 줄로 나가지만 맞는 폭도 넓어지고, 한 대를 잃어도 나머지로 계속합니다. 대열에 있을 때 잡거나 납치된 잠수함을 직접 쏘면 잠수함을 잃습니다(원작 갤러그 방식). 이 규칙은 타이틀과 1 스테이지 시작 화면에 안내됩니다.

### 보너스 스테이지

판마다 두 번, 서로 다른 패턴이 나옵니다. 공격은 하지 않습니다. 모두 채우면 퍼펙트 10000점입니다.

| 패턴 | 하는 일 |
|---|---|
| 물고기 떼 | 물고기 40마리가 화면을 크게 가로지릅니다. 경로 순서·속도가 판마다 달라집니다. 한 마리 100점 |
| 소용돌이 | 가운데에서 네 갈래 나선을 그리며 퍼지는 물고기 40마리. 한 마리 100점 |
| 표적 사격 | 과녁이 여기저기 잠깐 나타났다 사라집니다. 30개, 하나에 100점 |
| 황금 고래 | 크고 단단한 고래 한 마리(체력 24)가 천천히 헤엄칩니다. 맞힐 때마다 50점, 쓰러뜨리면 1000점 |
| 진주 줍기 | 쏘지 않고 **잠수함으로 줍는** 진주 24개가 화면을 튕겨 다닙니다. 하나에 100점 |

### 기록과 공유

게임 오버나 엔딩이 되면 결과 화면으로 넘어갑니다. 점수판은 하나이고, 이 기기의 브라우저에 **상위 10개**까지 저장됩니다(서버로 보내지 않습니다). 이번 점수가 10위 안에 들면(10위와 같은 점수는 제외) **이름을 입력**하고, 순위 · 이름 · 점수 · 스테이지 · 클리어 ★ 를 보여 줍니다. 이번 판 순위는 강조됩니다. 시작 화면에는 최고 점수가 나옵니다.
예전 버전의 기록(난이도별로 나뉘어 있던 점수판)은 처음 열 때 모두 합쳐 점수 순 상위 10개로 옮겨지고, 이름이 없던 기록은 `---`로 표시됩니다.
**공유** 버튼은 이름이 들어간 점수 카드 이미지를 만들어 공유 창을 띄웁니다(휴대폰). 공유를 지원하지 않는 브라우저에서는 문구를 클립보드에 복사합니다. **이미지 저장** 버튼은 카드를 PNG 로 내려받습니다.

## 설치와 오프라인 (PWA)

`npm run build` 로 만든 배포본은 홈 화면에 설치할 수 있고(`public/manifest.webmanifest`, 세로·전체 화면), 한 번 온라인으로 열면 이후 오프라인에서도 실행됩니다(`public/sw.js`: 같은 출처 파일을 캐시에서 먼저 보여 주고 뒤에서 갱신하므로 새 버전은 다음 실행 때 반영됩니다). 개발 서버(`npm run dev`)에서는 서비스 워커를 등록하지 않습니다. 설치하면 세로 고정도 실제로 동작합니다.

## 구조

```
src/
  game/    규칙 (화면·키보드·소리를 모르므로 node 에서 바로 테스트)
    paths.js      입장·급강하·돌진·가로지르기·지그재그·소용돌이 경로 (베지어)
    formation.js  40칸 대열: 모양 5가지, 흔들기와 벌어졌다 오므라들기
    enemy.js      적 한 마리의 상태와 종류별 급강하 (입장 → 대열 → 급강하 → 재입장, 문어의 소용돌이)
    boss.js       보스 공통 뼈대 (3단계·쓰러지는 연출), 크라켄/아귀/가오리/리바이어던은 kraken.js·angler.js·manta.js·leviathan.js
    bosses.js     보스 스테이지에 맞는 보스 고르기
    player.js     잠수함·어뢰·쌍둥이·연사 강화·방어막·새 무기 발사
    weapons.js    새 무기(확산·레이저·유도) 모양과 기체별 기본 공격, 스테이지별 아이템 분배
    ships.js      잠수함 3종(기본 공격·속도·시작 폭탄·필살기)
    specials.js   필살기 3종(대해일·어뢰 폭풍·심해 폭격)의 시작과 한 틱
    stage.js      스테이지별 대열 모양·새 적 섞기·입장 패턴, 보너스 계획과 패턴 5종, 보스 스테이지 판정
    game.js       점수·콤보·목숨·충돌·납치와 구출·필살기(폭탄)·아이템·보너스 진행·단계 진행·엔딩·이름 받기·기체 고르기·곡 이름(game.music)
  render/  canvas 그리기 (render.js), 공유 카드 이미지 (card.js)
  ui/      터치 조작
  app/     i18n (ko/en), 내 기록·이름 (records.js), 효과음과 배경 음악 합성 (sound.js)
public/    PWA: manifest.webmanifest · sw.js · 아이콘
IDEAS.md   아직 넣기로 정하지 않은 아이디어 메모
tests/     paths · formation · player · enemy · stages · kraken · extras · weapons · ending · game · records · i18n · music · ships
```

화면 크기는 224×288 논리 좌표이고 canvas 에는 2배로 그립니다. 게임 규칙은 효과음이 필요한 순간에 이벤트 이름(`game.events`)만 남기고, `main.js`가 그것을 `sound.js`로 넘깁니다.
속도·간격 같은 조정값은 `game.js`(`LIVES`, `COMBO_*`, `FINAL_STAGE`, `LATE_FROM`, `diveSpeed`, `maxDivers`, `diveInterval`, 필살기 상수는 `specials.js`, 기체는 `ships.js`)와 `enemy.js`(`SPD`, `BEAM_*`), 스테이지 구성은 `stage.js`(`MIX`, `ENTRY_PATTERNS`)에, 보스 패턴은 각 보스 파일에, 무기와 아이템 분배는 `weapons.js`(`WEAPON_DEF`, `WEAPON_FROM`, `ITEM_WEIGHTS`)에 모여 있습니다.
브라우저 저장소 키는 `deepstrike.records`(점수판), `deepstrike.name`(마지막 이름), `deepstrike.lang`, `deepstrike.mute`(효과음), `deepstrike.musicMute`(배경 음악), `deepstrike.ship`(마지막에 고른 기체) 입니다.
